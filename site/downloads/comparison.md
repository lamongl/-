# Skill 1.1.0 同条件试验结果

先更新、验证并安装 Skill，再开始两组制作。完整条件见 protocol.md；匿名独立评审见 blind-review.md。

## 条件

同一份论文（两组源文件SHA256均为961050c42058c934649497e003987d3b538995dc016d7196b66817dd299246be），相同继承模型和通用PPT制作工具。两组都要求8页、约5分钟、英文页面、逐页中文讲稿及末页备注8组中文备用问答，面向学术评委。仅实验组读取成品工作台Skill 1.1.0及quality参考。

本轮规格完整，不额外追问；因此不检验模糊需求下多轮澄清的效果。成品独立制作，结束前不互读材料加工结果。匿名副本随机分配为A、B，评审不读取组别映射或过程记录；评审完成后揭示A为未用工作台Skill，B为用了工作台Skill。

## 结果

| 项目 | 未用工作台Skill | 使用工作台Skill |
|---|---|---|
| 硬性条件 | 8页、8页中文备注、8组问答，通过 | 同左，通过 |
| 内容组织 | 三个核心论点清晰，方法性质表述准确 | 研究问题与中心论点前置，主线更紧凑 |
| 证据与局限 | 单独说明外部研究和中国政策边界 | 来源—作用—边界对照表更利于答辩 |
| 备用问答 | 覆盖主要基础问题 | 更集中于中国证据不足、因果推断及责任分配等质疑 |
| 各自长处 | Agent开发区分更明确，验证只检查定义属性的表述更精确 | 证据组织和防守性问答更强 |
| 视觉 | 简洁但偏平淡 | 增加2个可编辑表格，整体仍偏平淡 |
| 本轮墙钟时间 | 570.9秒，约9分31秒 | 333.558秒，约5分34秒 |

匿名独立评审认为B有小幅、实际的答辩可用性优势，未发现对原文的严重事实扭曲或明显裁切。主任务独立核对最终ZIP、8页、8页中文备注、末页8组问答及最终文件哈希与验证记录一致。

## 解释范围

结果支持新版Skill在这一任务中改善了证据组织和问答针对性，不能说明它对所有任务稳定有效。两组视觉差距不大，均缺少投影页面上的作者年份引用和具体完整示例。原文引用未经两组独立联网核验；没有在原生PowerPoint打开或口头计时。5分钟是规划，非实测。

计时包含工具配置、沙箱限制恢复与返工，两组并发也可能竞争资源，不能把本轮时间差全部归因于Skill，更不能据此承诺固定提速比例。此处“未用Skill”仅指未用成品工作台Skill，两组都使用通用演示文稿制作Skill。

## 本轮Skill更新及验证

- 多轮、材料驱动的关键问题，每轮1至3题；完整需求直接制作。

- 按成品类型验收，优先修复内容和可用性；只返工受影响部分。
- 工作台保留可展开的已确认回答。
- Skill源码和本机安装同步，格式验证通过；4个行为场景通过；7项连接器回归和隔离浏览器两轮追问、回答保留、下载、移动端检查通过。
- 本地发行包：release/delivery-workbench-codex-v1.1.0.zip，按15个文件白名单生成，不含用户材料。
