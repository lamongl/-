# 成品工作台 Skill 1.1.0 同条件试验

先完成Skill修改、结构验证、行为场景验证与本机安装，再开始两组实际制作。此前对照组准备已暂停，实际计时从恢复任务起算。

## 共同要求

同一份原始论文 DOCX；面向学术答辩评委；恰好8页；汇报约5分钟；英文页面；每页中文讲稿；末页备注包含8组中文备用答辩问答；重点是研究问题、论证、贡献和局限；克制专业的学术风格；实际可编辑PPTX。

两组继承相同模型，使用相同版本的通用演示文稿制作Skill和本地artifact-tool。对照组不读取成品工作台或提示词优化Skill；实验组读取更新后的deliver-workbench及quality参考。任务规格已完整，两组均直接制作，不再重复追问。此次比较内容制作流程，不测试界面本身或模糊需求的澄清效果。

两组使用独立上下文和输出目录，制作期间不读取旧成品、彼此产物或构建脚本。制作组可以访问相同原始文档、工具与公开来源。过程结束后统一由主任务检查。

## 检查标准（制作完成前固定）

1. 硬性要求：8页、双语分工、逐页讲稿、8组问答、文件真实可用。
2. 内容与证据：研究问题是否明确；是否准确表达研究性质；论点是否有依据；贡献与局限是否恰当；是否虚构数据或因果关系。
3. 答辩可用性：主线、重点、五分钟容量、讲稿与页对应、备用问答针对性。
4. 视觉表达：图示是否解释关系；可读性、信息密度、重复内容与版面缺陷。
5. 效率：记录墙钟时间、错误及返工；两组并发，资源竞争和工具延迟会影响计时，不能据此作严格速度结论。

单次、非盲、同一模型试验只能给出探索性结果；通用制作Skill两组共用，因此“未用Skill”准确指未用成品工作台Skill。不得预设实验组胜出，或把格式检查通过当作内容优质。
