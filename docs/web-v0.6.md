# 网页版 v0.6：只生成提示词 / Prompt builder only

访问 / Website: https://lamongl.github.io/-/

按用户决定，撤回 v0.5 的模型接入。移除 API Key、模型设置、调用按钮、AI正文输出与相关代码；无需登录或充值。网页根据本地规则整理提示词，用户复制到自行选择的 AI 中执行。本页不执行任务，也不声称经过模型评审。

保留报表、文档、PPT、检索摘要四类独立示例；按需逐题补充；格式、风格、已有资料链接；UTF-8 TXT/MD/CSV附件原文；语音输入、全文复制、TXT下载与设备支持时的系统分享。

任务文字和附件在当前页面处理，不上传本站，不保存历史。浏览器语音在线识别仍需明确允许，音频可能由浏览器识别服务处理；本站不保存录音。复制或分享后的内容由接收应用处理。资料链接不会由本页读取。

发布白名单排除模型客户端，页面及本地服务器恢复 `connect-src 'none'`。构建检查验证无密钥输入、无模型执行按钮、无模型客户端导入；核心功能与语音逻辑使用现有自动化测试。模拟语音测试不能证明真实麦克风识别准确率。不承诺质量提升或 token 节省。

English: v0.6 removes the v0.5 API integration. The website builds prompts locally without API keys, model calls or payments. Copy the prompt into your chosen AI. Existing examples, attachments, dictation and export remain. Remote browser speech recognition requires explicit opt-in; this site stores no recordings. Quality and token savings have not been established.
