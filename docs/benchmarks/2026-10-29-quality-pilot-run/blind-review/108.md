# 任务

为全体员工写一份可直接发布的中文系统维护通知，250字以内。只用下列合成材料，发生冲突以已确认版本为准，不补造信息。
[草案，10月27日] 10月31日21:00—22:00，全部系统不可用，办公室现场培训取消。
[运维确认版，10月29日] 维护时间改为10月30日22:00—23:30；只影响报销系统，期间无法登录或提交；其他系统可正常使用。维护前保存未提交内容并避开该时段办理报销。预计恢复时间是23:30，如有延迟另行通知。
[行政补充，10月29日] 与培训无关，不要在本次通知提培训。尚未确认负责人、联系电话或补偿安排。
清晰说明时间、影响范围、员工行动及恢复的不确定性。
