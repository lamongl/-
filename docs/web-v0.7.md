# 网页版 v0.7：Office / PDF 资料读取

在原 GitHub Pages 站点上扩展「参考资料」区域。拖拽和点击选择使用同一读取流程，最多 5 份，每份 20 MiB（界面简写为 20 MB）。

支持 UTF-8 TXT、MD、CSV，以及 Word DOCX、Excel XLSX/XLS、PPT PPTX、带可提取文字的 PDF。Word 提取正文和表格；Excel 按工作表保留格式化的缓存值、空单元格位置及零值，不执行公式；PPT 依照演示文稿的关系顺序读取文字和演讲备注；PDF 按页提取文字。提取内容纳入最终提示词，支持移除附件。

旧 DOC/PPT 需要先另存为 DOCX/PPTX。读取不还原排版、不分析图表或图片；扫描 PDF 需要先 OCR。PDF 任意一页没有文字时会拒绝整份文件并提示页码，以免将部分读取当成完整读取。无缓存结果的 Excel 公式会提示先重新计算并保存。损坏、加密、空白、不支持的文件显示错误，其他有效文件继续读取。

单份提取内容最多 100 万字符；Office XML 单条目解压最多 8 MiB、合计最多 50 MiB。超限拒绝且不自动截断。原始文件大小上限不代表任何小于20MB的文件都一定可解析。

所有文件内容只在浏览器内存中处理，不上传。解析脚本、PDF worker、字体和字符映射随站点发布；CSP 仅允许同源资源请求，禁止外部连接和对象执行。解析库锁定于 package-lock.json，运行与部署前使用 npm ci 安装，许可证随静态构建发布。

验证：26 项 Node 测试通过；独立 Edge 无界面浏览器实测生成的 DOCX、XLSX、XLS、PPTX、PDF 经按钮子元素拖放一次导入5份，核对中文、前导零、零值、演讲备注及最终提示词内容，第6份被拒绝，页面无未捕获异常。未覆盖所有 Office/PDF 生产器、扫描OCR、图片、图表、复杂PDF阅读顺序或全部移动浏览器。
